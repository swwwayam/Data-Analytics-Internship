# GPI Data Analytics Internship

## Overview

This repository contains the work completed as part of the **Global Professional Internship (GPI) – Data Analytics Program** conducted by **Cloud Counselage Pvt. Ltd.**

The project focused on analyzing student event-registration data to identify insights into the relationship between **academic performance, economic background, Python programming experience, event participation, and expected salary**.

The analysis was performed on a dataset containing **4,894 event registrations across 16 attributes**, with Python-based exploratory data analysis and supporting visualization and documentation.

---

## Project Objective

The primary objective of the project was to address the lack of data-driven insights into how factors such as:

* Academic performance (CGPA)
* Family income
* Python programming experience
* Graduation year
* City
* Leadership experience
* Event participation
* Promotion channels

relate to student participation and expected salary.

The project involved data understanding, preprocessing, exploratory analysis, visualization, interpretation of results, and documentation of the findings.

## Key Findings

Some of the major findings from the analysis include:

* The dataset contains **4,894 event registrations** representing **2,157 unique students**.
* The average student CGPA is approximately **8.04**.
* **92.5%** of the records fall within the **₹0–2 Lakh family-income bracket**.
* Students with higher Python experience tend to have higher expected salary expectations.
* Students with a CGPA of **9–10** reported substantially higher expected salaries than students in lower CGPA ranges.
* **WhatsApp** was the leading promotion channel, accounting for approximately **21.8% of registrations**.
* Data Science and Artificial Intelligence-related events recorded strong participation.
* Leadership experience showed little difference in average CGPA or expected salary within this dataset.
* Students with both above-median CGPA and above-median Python experience had an average expected salary of approximately **₹15.14 LPA**.

These findings provide insights into student engagement, employability factors, and potential areas for improving outreach and skill-development programs.

## Methodology

The project followed a structured **Exploratory Data Analysis (EDA)** workflow:

1. **Data Loading**

   * Imported the dataset into Python.
   * Examined dataset dimensions, data types, and basic statistics.

2. **Data Cleaning & Preprocessing**

   * Checked for missing values and datatype consistency.
   * Normalized string-based attributes.
   * Performed data validation and de-duplication where required.

3. **Exploratory Data Analysis**

   * Used Pandas operations such as `groupby`, `value_counts`, filtering, quantiles, and aggregation.
   * Analysed relationships between academic, demographic, technical, and salary-related attributes.

4. **Data Visualization**

   * Created visualizations using Matplotlib.
   * Used visual analysis to examine student distributions and participation patterns.

5. **Interpretation**

   * Each analytical question was accompanied by a conclusion and interpretation of the results.

6. **Dashboard & Reporting**

   * Supporting visualization and dashboard work was also completed using Power BI.
   * Findings were documented through project reports and submission documents.
